# Hotel Booking Analytics Dashboard | Power BI

## Project Overview
This project analyzes hotel booking data using Power BI to understand booking trends, cancellation patterns, and average daily rates for City Hotels and Resort Hotels.

## Tools Used
- Power BI Desktop
- Power Query
- Data Visualization

## Dashboard KPIs
- Total Bookings
- Cancellation Rate
- Average Daily Rate (ADR)

## Visualizations
- Average Daily Rate by Hotel
- Bookings by Hotel Type
- Cancellation Rate by Hotel
- Top 10 Countries by Bookings
- Monthly Cancellation Trend
- Average Daily Rate by Hotel Type

## Dataset Source
Hotel Booking Demand Dataset — Kaggle  
https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand

## Project Objective
To analyze hotel booking data and present insights through an interactive dashboard that supports better understanding of booking performance and cancellation behavior.
